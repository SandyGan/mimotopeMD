# Case 2 — aεFab

This directory contains the input files and analysis data for molecular dynamics simulations of the aεFab system. The CHARMM-GUI-generated inputs cover the minimization, equilibration, and production stages.

## Running the simulation

Run `./RUN` directly to start GROMACS from scratch:

```bash
./RUN
```

`RUN` performs energy minimization, equilibration, and five consecutive production segments. In `step5_production.mdp`, `dt = 0.002 ps` and each segment contains `100,000,000` steps. Each segment therefore represents 200 ns, for a total production time of 1,000 ns (1 μs).

The current script uses GPU 0 and 12 CPU threads. Adjust these settings for the available hardware and ensure that `csh` and `gmx` are available before starting the simulation.

## Contents

| File or directory | Description |
| --- | --- |
| `RUN` | Complete C shell workflow from minimization through five production segments. |
| `step3_input.gro/.pdb/.psf` | Initial simulation structure. |
| `step4.0_minimization.mdp` | Energy-minimization parameters. |
| `step4.1_equilibration.mdp` | Equilibration parameters. |
| `step5_production.mdp` | Production parameters for one 200 ns segment. |
| `index.ndx` | GROMACS atom-group index. |
| `topol.top`, `toppar/` | System topology and force-field parameters. |
| `data/output.xvg` | Concatenated time, RMSD, and Rg data from three independent 1 μs replicates; 30,003 rows in total. |
| `data/gibbs.xpm` | RMSD–Rg Gibbs free-energy map generated by `gmx sham`. |
| `data/gibbs.log` | FEL local minima and their corresponding energies. |
| `data/bindex.ndx` | Cluster frame indices associated with the relative-free-energy grid cells or intervals. |
| `data/contact_frequency_data.xlsx` | Time-resolved peptide-residue–antibody contact frequencies for `Rep_1`–`Rep_3`, plus summary worksheets; values are summarized in 40 ns intervals (400 frames sampled every 100 ps). |

The three columns in `output.xvg` are time (ps), RMSD (nm), and Rg (nm). Each replicate spans 0–1,000,000 ps. The FEL plotting script multiplies coordinates by 10 by default to convert nm to Å.
