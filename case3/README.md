# Case 3 — MW01

This directory contains the input files and analysis data for molecular dynamics simulations of the MW01 system. The CHARMM-GUI-generated inputs cover the minimization, equilibration, and production stages. Six independent 1 μs trajectories are provided as two three-trajectory analysis sets: Traj1–3 and Traj4–6.

## Running the simulation

Run `./RUN` directly to start GROMACS from scratch:

```bash
./RUN
```

`RUN` performs energy minimization, equilibration, and five consecutive production segments. In `step5_production.mdp`, `dt = 0.002 ps` and each segment contains `100,000,000` steps. Each segment therefore represents 200 ns, for a total production time of 1,000 ns (1 μs).

The current script uses GPU 0 and 12 CPU threads. Adjust these settings for the available hardware and ensure that `csh` and `gmx` are available before starting the simulation.

## Contents

| File or directory | Description |
| --- | --- |
| `RUN` | Complete C shell workflow from minimization through five production segments. |
| `step3_input.gro/.pdb/.psf` | Initial simulation structure. |
| `step4.0_minimization.mdp` | Energy-minimization parameters. |
| `step4.1_equilibration.mdp` | Equilibration parameters. |
| `step5_production.mdp` | Production parameters for one 200 ns segment. |
| `index.ndx` | GROMACS atom-group index. |
| `topol.top`, `toppar/` | System topology and force-field parameters. |
| `data/output1-3.xvg`, `data/output4-6.xvg` | Concatenated time, RMSD, and Rg data for Traj1–3 and Traj4–6, respectively; each file contains three independent 1 μs trajectories and 30,003 rows. |
| `data/gibbs1-3.xpm`, `data/gibbs4-6.xpm` | RMSD–Rg Gibbs free-energy maps generated by `gmx sham` for the two trajectory sets. |
| `data/gibbs1-3.log`, `data/gibbs4-6.log` | FEL local minima and their corresponding energies for the two trajectory sets. |
| `data/bindex1-3.ndx`, `data/bindex4-6.ndx` | Cluster frame indices associated with the relative-free-energy grid cells or intervals for the two trajectory sets. |
| `data/contact_frequency_data1-3.xlsx`, `data/contact_frequency_data4-6.xlsx` | Time-resolved peptide-residue–antibody contact frequencies and summary worksheets for Traj1–3 and Traj4–6. Values are summarized in 40 ns intervals (400 frames sampled every 100 ps). |

The three columns in each `output*.xvg` file are time (ps), RMSD (nm), and Rg (nm). Each trajectory spans 0–1,000,000 ps. Within each contact-frequency workbook, the three trajectories in that file are labeled `Rep_1`–`Rep_3`; the workbook filename identifies whether they correspond to overall Traj1–3 or Traj4–6. The FEL plotting script multiplies coordinates by 10 by default to convert nm to Å.

The Traj1–3 and Traj4–6 XPM files are also mirrored in [`../special_notes/`](../special_notes/README.md), which additionally provides an FEL generated from all six trajectories and documents the corrected XPM rendering workflow.
